## Folio 1.1.0

The first public release of Folio, a fast and lightweight notes app for homework and projects, by Playtale Works.

## Important Notice: Folio Development & Distribution

Folio will be moving to the official **Playtale GitHub repository**. As a result, **supuko/Folio will remain the legacy version**.

This does not mean development will stop. supuko/Folio will continue to receive updates, with the following distinction:

- **Test versions:** Experimental builds and ongoing updates will be published here.
- **Final releases:** Completed and finalized versions will be published on the official Playtale GitHub repository.

Please keep in mind that experimental versions may contain bugs, incomplete features, or unexpected issues. We will always do our best to identify and resolve these problems.


### Highlights
- Live split view: write on one side, see the formatted note update on the other
- Paste code and Folio detects the language (Bash, Python, JavaScript, HTML, CSS, SQL, JSON, Java, C/C++, PHP, PowerShell) and highlights it
- Nested folders, #hashtags, due dates, pinned notes, and Ctrl+K quick open
- Checklists you can tick off, with progress shown in the note list
- Drawing tool and pasted screenshots
- Three themes: Neutral, White and Black
- Export notes as .folifile or TXT, plus whole-workspace Backup and Import

### Download
Get **Folio.exe** below. It's portable, so there's nothing to install. Double-click it to start.

Requires Windows 10 or 11 (64-bit).

### First launch
Windows may warn about an "unknown publisher" because the app isn't code-signed. Select **More info**, then **Run anyway**. The full source is in this repository if you want to check it.

### Your notes
Notes are stored on your computer only, with no accounts and no network access. Use Backup now and then, especially if you use the browser version.
